SentinelGuard Web Filter — Setup

This extension talks only to the SentinelGuard agent running on your own computer at 127.0.0.1. Pair it once by pasting the agent's token below.

Find the token in the file %APPDATA%\SentinelGuard\agent_token (Windows) — open it in Notepad and copy its contents. Nothing here is sent anywhere except your own machine.
